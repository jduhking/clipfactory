# Keena the Void Slayer trailer (sample video)

`keena-trailer-3d-intro.mp4` is a sample video to try Clip Factory on: the Keena the Void Slayer trailer with a new
3D cold open. It is 79.4 s long, 1920×1080 at 30 fps, H.264 video with AAC stereo sound, 46 MB.

| Time | What happens |
|---|---|
| 0–6 s | New 3D intro. The camera starts low in the grass at Keena's boots and circles up to a tall hero shot of her. |
| 6–12 s | It swings behind her as the sky darkens and voidlings swarm across Leporidia. Void flashes hit at 9.6 s and 12.9 s. |
| 12–15.5 s | It reveals the giant tree and beehive being corrupted under a void vortex, then fades to black. |
| 15.5–79.4 s | The original trailer, without its old 3D shot (9.0–13.07 s of the original). That shot is exactly 8 beats long, so the music stays on the beat. |

The intro's music and sound effects are generated by `generator/audio_intro.py`.

## Rebuild it

You need:

- Node 20 or later and ffmpeg;
- Python 3 with numpy, scipy and soundfile (point `PYTHON` at it), or uv, which the script then uses to fetch them;
- the original trailer, `keenathevoidslayertrailer.mp4`, from the
  [Knowledge Base](https://factory.8090.ai/project/8285d823-63bb-4371-8922-2c2c4975ec86/knowledge-base/7c45dd12-4742-434d-a822-050440785cf4).
  It is not in the repo.

```sh
cd samples/keena-the-void-slayer/generator
bash build.sh /path/to/keenathevoidslayertrailer.mp4
```

The script:

1. installs the Node packages and Playwright's Chromium;
2. renders the 465 intro frames in software (SwiftShader), so no GPU is needed. This takes about 13 minutes on 8 CPU
   cores; set `WORKERS` to change the number of parallel renderers;
3. makes the music and removes the old 3D shot from the original;
4. writes `out/keena-trailer-3d-intro.mp4` (two-pass H.264 at 4.6 Mbps, as committed here) and `out/intro-3d.mp4`
   (the intro on its own).

If rendering stops, run the script again: it skips frames that are already on disk. Delete `out/frames` after you
change the scene. To update the sample, copy the new video over the one in this folder.

To check a change without rendering every frame, render stills at chosen times from `generator/`:

```sh
python3 -m http.server 8391 --bind 127.0.0.1 &
node shoot.mjs out/stills 960 540 t=1.5 t=6.6 t=14.6
```

## What is where

| File in `generator/` | Contents |
|---|---|
| `scene/main.js` | The timeline: camera path, void flashes, corruption, fades. `DURATION` is 15.5 s. |
| `scene/keena.js` | Keena and Moku |
| `scene/world.js` | Terrain, grass, sky, mountains, the giant tree and hive, voidlings, particles |
| `scene/toon.js` | Toon shading, outlines, fog and sky colours |
| `scene/geom.js` | Geometry and noise helpers |
| `render-frames.mjs`, `shoot.mjs` | Headless renderers: every frame for the video, or stills for checks |
| `audio_intro.py` | The intro's music and sound effects |
| `assemble_audio.py` | Removes the old 3D shot from the trailer's sound and joins it after the intro |
| `build.sh` | Runs all of the above, then encodes |

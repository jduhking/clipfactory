Made on your Mac.

Our first beta is for small streamers on Apple Silicon Macs. Join with your Mac model and what you stream. Comfortable in Terminal? You can set it up from source below.

Set it up ↓Join the waitlist →

Signed, notarized installers come with the first signed release. Until then, set it up from source in a few commands.

Pick your computer

Mac first.
Windows and Linux too.

Each setup script checks what is missing and explains it before installing anything. Then the app walks you through the speech model, and optionally Ollama, in Settings → Models.

Mac

Initial beta target: Apple Silicon.

Signed and notarized installer: with the first release

  • macOS on Apple Silicon for local speech; Intel Macs use cloud speech or an imported transcript
  • Python 3.11 or 3.12 (native arm64) and Node.js 22.12 or newer
  • FFmpeg with caption support; the script can install Homebrew's ffmpeg-full
Terminal
git clone https://github.com/jduhking/clipfactory.git
cd clipfactory
bash scripts/setup-mac.sh
.venv/bin/clip-factory

Windows

Signed installer: with the first release

  • Windows 10 or 11, x64, for local speech; ARM uses cloud speech
  • Python 3.11 to 3.13 (x64) and Node.js 22.12 or newer
  • Microsoft Edge WebView2, included in Windows 11
PowerShell
git clone https://github.com/jduhking/clipfactory.git
cd clipfactory
powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1
.venv\Scripts\clip-factory.exe

Linux

AppImage: with the first release

  • x64 with a desktop session, for local speech; ARM uses cloud speech
  • Python 3.11 to 3.13 and Node.js 22.12 or newer
  • A Secret Service key store, such as GNOME Keyring or KWallet, to save API keys
Terminal
git clone https://github.com/jduhking/clipfactory.git
cd clipfactory
bash scripts/setup-linux.sh
.venv/bin/clip-factory

First run

From install
to first clip.

About 20 minutes plus processing time. The first-clip tutorial walks through every step.

  1. 01

    Describe your channel

    In the Brand profile: your name, who watches, your voice and the topics to avoid. Every clip starts from it.

    Set up speech once

    The app offers a one-time speech model download (about 3 GB), or cloud speech with your own Groq key.

  3. 03

    Pick the AI model

    Pick a long video, approve your Style rules and choose Find clips.

Your processing choices

Local first.
Cloud when you choose.

The app tells you before anything leaves your computer. Exactly what is sent where.

Local media and models

Episodes, clips and results are stored on your computer. Transcription, local models and rendering work offline once set up.

Optional cloud models

With your own key, agents send text, and still frames only if you allow it. Cloud speech sends the episode's audio. You pay the provider directly.

Connected posting

On Pro and Business, connect TikTok, Instagram, YouTube, Facebook, LinkedIn, X or Threads. Only approved clips post; schedules run while the app is open.

Before you start

Useful details.

Is there an installer I can download now?

Not yet. Signed and notarized installers for Mac and Windows, and a Linux AppImage, come with the first signed release. Until then, the setup scripts above install from source. Email us to hear when installers are ready.

How much disk and memory do I need?

Room for your episodes and clips, plus about 3 GB for the speech model. Local agents need at least 8 GB of RAM (12 GB recommended); with less, use a cloud key. See Models and AI settings.

Which FFmpeg build do I need?

One with caption support (libass). The Mac setup can offer Homebrew's ffmpeg-full, the Windows setup can install Gyan's build with winget, and most Linux distribution packages include it. Each script checks before it renders.

Do I need an account?

Not to start: signed out, the app works as Free. Sign in to upgrade, or to connect accounts and post from the app.

Where do I learn the app?

The user guide covers every screen, and Help in the app opens it. Questions: jamesbodebiyi@gmail.com.
